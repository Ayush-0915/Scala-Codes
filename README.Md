## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Ayush-0915/Scala-Codes.git
```

Move into the project folder

```bash
cd Scala-Codes
```

---

## ▶️ Running a Scala Program

Using Scala CLI

```bash
scala run Variables.scala
```

Compile

```bash
scalac Variables.scala
```

Run

```bash
scala Variables
```
